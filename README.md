# 🌐 Simple HTML & CSS Website

A modern and visually appealing website built using pure HTML and CSS. This project features a clean navigation bar, a full-screen hero section with a background image overlay, and interactive buttons.

## ✨ Features

- Clean and modern navigation bar
- Full-screen background image
- Dark transparent overlay using CSS pseudo-elements
- Centered hero section with attractive typography
- Interactive buttons with hover effects
- Smooth CSS transitions
- Flexbox-based navigation layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

## 📂 Project Structure

```text
simple-html-css-website/

```

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## 📸 Preview

The website includes a full-screen hero section with a camera background, dark overlay, navigation links, and call-to-action buttons.

## 🎯 Purpose

This project was created to practice and strengthen my understanding of HTML and CSS, particularly Flexbox, positioning, pseudo-elements, background properties, and hover effects.
